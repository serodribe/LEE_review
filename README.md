# LEE_review

Classical studies of the **look-elsewhere effect (LEE)** in bump-hunt searches.

The notebook [`notebooks/experiments.ipynb`](notebooks/experiments.ipynb) covers:

1. **Classical bump hunt**
   - Null distribution of the test statistic $q$ and local $p$-values, fixed vs. scanned mass
   - Gross & Vitells correction (upcrossings); Davies, GV and empirical trials factors
   - Gross–Vitells vs. Bonferroni trial factors
   - Bayer & Seljak estimate without pseudo-experiments
   - Dependence of the trial factor on the signal template width
2. **Multi-channel search**
   - Particle decay channels
   - Unknown physics process
   - Bonferroni, Šidák and Benjamini–Hochberg corrections

The notebook only shows the results: the pseudo-experiments are generated by the scripts in [`scripts/`](scripts/),
which save their output in `output/data/`. Figures are written to `output/plots/classic/`.

## Usage

1. Generate the data (from the repository root; each script uses all CPU cores but two by default, `--n-jobs N` to change it).
   The seeds are fixed and the results do not depend on the number of jobs.

   | Script | Notebook section | Output |
   |---|---|---|
   | `python scripts/run_trials_factor.py` | 1.1, 1.2, 1.4 | `output/data/single_channel/q_fixed_m0.npz`, `trials_factor_{100,350}.npz` |
   | `python scripts/run_grid_scan.py` | 1.3 | `output/data/single_channel/grid_scan.npz` |
   | `python scripts/run_width_scan.py` | 1.5 | `output/data/single_channel/width_scan.npz` |
   | `python scripts/run_multichannel_6ch.py` | 2.1 | `output/data/multichannel_6ch/` |
   | `python scripts/run_multichannel_50ch.py` | 2.2 | `output/data/screening_50ch/` |

2. Run the notebook from inside `notebooks/` so the relative paths resolve correctly.

Common settings and functions (model, vectorised profile-likelihood fits, GV / Davies / Bayer–Seljak helpers,
multiple-testing procedures, plot style) are in [`scripts/LEEutils.py`](scripts/LEEutils.py).
